# Simulado Inteligente TEMFC (SBMFC)

Simulador de provas para obtenção do **Título de Especialista em Medicina de Família e Comunidade (TEMFC)** promovido pela **SBMFC**.

## 📌 Funcionalidades
- **Banco de Quase 400 Questões Reais:** Extraídas dos cadernos e gabaritos definitivos oficiais (TEMFC 37, 36, 35, 34, 30 e anteriores).
- **Questões Sortidas:** A cada simulado iniciado, o sistema seleciona perguntas aleatórias de edições variadas para garantir um treino realista e imprevisível.
- **Configuração de Prova:** Escolha entre 20, 40, 60 ou 80 questões, com cronômetro opcional (3 min/questão).
- **Correção Oficial:** Linha de corte em **70%** para determinar status de **APROVADO(A)** ou **NÃO APROVADO(A)**.
- **Revisão Detalhada:** Comparativo da sua resposta com o gabarito oficial e atribuição de ponto para questões anuladas pós-recurso.
- **Histórico no navegador:** Ao finalizar, o resultado fica salvo no `localStorage` (média, melhor nota, desempenho por edição e lista dos últimos simulados).

## 🚀 Como Executar
Não requer instalação de dependências ou servidores.
Basta abrir o arquivo `index.html` em qualquer navegador web.
